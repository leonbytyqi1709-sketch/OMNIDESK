omnidesk_spezifikation_v2.pdf im Projektroot).

WICHTIG – lies zuerst diese Dateien im Projektroot:

     naechste Schritte, Ideen)
  3. omnidesk_spezifikation_v2.pdf  (fachliche Spezifikation)

STACK: Vite 8 + React 19 + TypeScript strict, Tailwind v4 (CSS-Config
in src/styles/globals.css, kein tailwind.config.js), Shadcn/ui,
React Router v7 (Lazy Loading ueber src/config/modules.ts),
TanStack Query, Clerk (Auth), Drizzle ORM + Neon Postgres,
Hono-API-Server unter server/ (Port 8787, Vite-Proxy /api),
megajs fuer MEGA Cloud Storage.

START DER ENTWICKLUNGSUMGEBUNG:
  1. Zwei Terminals:
     Terminal 1: npm run dev        (Frontend, Port 5173)
     Terminal 2: npm run dev:api    (Hono API, Port 8787)
  2. .env.local ist bereits vollstaendig konfiguriert
     (VITE_CLERK_PUBLISHABLE_KEY, DATABASE_URL, GOOGLE_CLIENT_ID,
      GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI).

REGELN (unveraendert einhalten):
  - Farbthema strikt: Hintergrund #09090b, Kacheln #18181b, Text
    #fafafa, Sekundaertext #a1a1aa, Gradient #230d8f -> #cf0a0a.
    Fertige Utilities: bg-gradient-accent, text-gradient-accent,
    glow, glow-strong. Nur Shadcn-Komponenten verwenden.
  - Strikte Modultrennung: jedes Modul unter src/modules/<id>/ mit
    index.tsx als einzigem Export; neue Module NUR ueber die
    Registry src/config/modules.ts anmelden. Ein Drizzle-Schema
    pro Modul in src/db/schema/, immer mit user_id + Index.
  - Jede Aenderung mit npm run build verifizieren (muss 100% gruen sein).
  - UI-Texte auf Deutsch. Toasts (Sonner) fuer Erfolg/Fehler.
